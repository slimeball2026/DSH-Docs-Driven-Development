# L2：无 frontmatter 的 md 必须能 `edit`

**背景**：M1 时期，`docs/` 下没有 frontmatter 的 md 会被门禁永久锁死——
`edit` 被拒，而拒绝文案让你"先补上 id/role/status"，可补字段又只能用 `edit`。死锁。
M1.5 的 N1 修法应该解开它。

**操作**：
1. 用 `read` 读 `docs/plain-note.md`；
2. 用 `edit` 把这一句：
   `> 复核时：直接 \`edit\` 这一行，把「可写」改成「真的可写了」，看能不能成功。`
   改成：
   `> 复核时：L2 已验，这一行是 edit 写进去的。`
   （只改这一行，别动别的）

**通过标准**：
- `edit` 返回 `The file ... has been updated successfully.`（或等价的成功文案）
- **不是** `Error: ... frontmatter ...` 这类拒绝

**如果失败**：把完整错误原文贴出来。这条失败意味着 N1 的修法在实机上没生效。
