## 0. 这个项目究竟是什么（**先读这一节**）

> 这一节被漏过三次（三个不同作者），所以强制保留。

### 0.1 一句话

> **让 AI 在动手改项目文档之前，必须先读过该读的文档；「读没读」由插件记账并强制，不是靠提示词嘱咐。**

这是一个 **DSH 全局插件**，名字叫「文档驱动开发」（DDD，**不是**领域驱动设计）。
它被 profile 用 junction 链接（`@local/ddd` → 本仓库 `ddd-bundle/`）。

### 0.2 四个环节

| # | 环节 | 落点 | 一句话 |
|---|---|---|---|
| 1 | 激活判定 | `adapters/probe.js` | 探不到标记 → **整个插件对该项目 no-op** |
| 2 | 扫描建注册表 | `docs/scan.js` + `adapters/registry.js` | 坟场永不进索引；readSet 是 `WeakMap` 内存态 |
| 3 | 索引注入 | `adapters/inject.js`（`systemPrompt.context()`） | 每轮塞 `【门禁】/【预算】/【怎么做】/【已读】/【未读】` |
| 4 | **门禁** | `adapters/guard.js`（`ctx.tools.guard()`） | 模型写 `docs/` 时按路径判，**没读过就拒** |

**关键在 3 与 4 的分工**：3 只是"让人看见清单"，**4 才是那个 `if`**。

### 0.3 三条铁律（破坏了项目就失去意义）

1. **门禁必须是代码里的 `if`**，不是提示词嘱咐；
2. **全局挂载，项目级生效**（S1，不做 preset）；
3. **Q1–Q13 / R1–R5 / S1 / S2 / M1-Q / P / M2-Q 已冻结** —— 改冻结决策必须有用户授权记录。

> ⚠️ **M2.7 有两次获得授权动了它们**（都记在 §2）：
> 「关门禁实验」和「交接硬门禁降级为提示词层」。

### 0.4 术语

| 词 | 含义 |
|---|---|
| **标绿** | `doc_mark(id, status: 'authoritative')` —— `authoritative` 在 UI 里显示成 🟢✅ |
| **坟场** | `docs/_graveyard/`，只读、不进索引 |
| **M0-5 红线** | 索引块不得含快变量（时间戳/轮次/百分比） |
| **pinned** | 索引块里永不裁剪的段（门禁/项目/施工/预算/怎么做） |
| **标绿快照** | `_artifacts/ddd-mark-snapshots.json`，M2.6 新增，H-6 的数据源 |
| **片段读** | `read(offset=N, limit=M)` —— 只拿到文件的一部分 |
| **返工成本** | 一次失败之后要几步才回到"能写"（M2.7 的量化口径） |

### 2.3 三条已验证为真的结论

1. **门禁不是成本来源**（关门禁实验）：关掉后错误从 1 降到 0，但步数从 28 **涨**到 34、
   字符从 11 332 涨到 16 335，纯流程成本 50%→59%。
   ⇒ 那 22 次"失败后的恢复步数"**不是门禁制造的多余动作**，AI 没有门禁时依然会做。
   门禁只是把它们**显式标记成失败**，让我们看见了。
   **门禁是刹车，不是负担。**
2. **`doc_health` 被当仪式反复跑**：3→4→**7** 次，且多数结果相同。关掉门禁不会让它减少。
3. **三轮不同模型独立收敛到同一顺序**：
   「所有内容文档定稿 → `doc_health` 归零 → 建交接 → 最后标绿」。
   ⇒ **问题在流程结构，不在模型能力。**

### 2.4 【重要】我上一轮的修复是错的，本轮自己推翻了

`20cf9da`（修法 2）假设"片段读会记下旧指纹 → 误拒"。**实测方向相反**：

```
1 没读过                     → 拒绝（必须先读）
2 完整读后                   → 放行
   （自己 edit 成功一次）
3 自写后 + pre-step（未重读）  → 拒绝：你读过的是 vf6fecf，磁盘已是 v5ecdee
   （read(offset=53, limit=15)，读到文件末尾）
4 片段读之后                 → **放行**   ← 片段读把正确拒绝推开了
```

根因两层：
- **判据错了**：`textFromReadResult` 只看 footer 是不是 `End of file`。
  但 `offset` 读到文件末尾时 footer **也是** `End of file` → 判成"整份读完" → 算出**片段指纹**。
- **两处各写一遍**：`textFromReadResult` 和 `windowReadOf` 都只看 footer，
  重复本身就是缺陷来源。

`markRead` 的 A 分支随后**同时**改写注册表与 readSet → 两边相等 → 放行。
而开合取决于"中间有没有 pre-step 重算注册表"——**纯时序运气**。

⇒ `c85ab8b` 用 **A 方案**修掉：片段读**完全不记账**，判据合并成一处 `envelopeOf()`，
`registry.js` 删掉 2725 字符的 `opts.window` 分支。

**这条教训值得记住**：修之前先**证明缺陷存在**，别照着上一轮的描述修。

## 4. 坑（**这些坑我全踩过，别再踩**）

### 4.1 写测试时最贵的三个坑

| 坑 | 我踩了几次 | 症状 | 正解 |
|---|---|---|---|
| **探针没激活** | 3 次 | 所有断言"放行"，测了个寂寞 | 先写一条**前置断言**（"没读过的必须被拒"），不通就说明装配没激活 |

| **`editArgs` 覆盖了 `file_path`** | 1 次 | `{ file_path: app.file, ...editArgs() }` 展开把路径变成 `undefined` | 辅助函数里**不要**带 `file_path` |

### 4.2 变异检验的坑（§4.5 那条纪律救了我 N 次）

**变异存活时，按这个顺序查**：

1. **变异真的施加了吗？** —— 锚点命中 0 次 → BAD-ANCHOR，是锚点问题不是测试问题；
2. **测试跑到了吗？** —— 这是**最常中的**。我踩过的：
   - `observe.test.js` 是**纯函数**层，抓不住 `createObserver` 的**接线**；
   - 必须加 `m27-window-read-real.test.js`（真实 `apply()` 装配）才覆盖到；
3. **变异等价吗？** —— 我试过 3 次都写成等价变异（代码结构让它不改行为）。

**结论**：`_m23/mutate-drill-fixes.mjs` 的测试文件列表**必须**包含被改动代码的所有覆盖层。
那个列表已经长到 12 个文件，加新功能时**记得加**。

### 4.3 行尾 CRLF 会让变异锚点**静默失效**（本轮挖出的真 bug）

**症状**：3 条变异的 `CAUGHT` 一直是**假的**——它们从来没被施加过。

**根因**：
```
ddd-bundle 下 .js/.mjs：CRLF 6 个，LF 86 个
core.autocrlf = true，.gitattributes 不存在
```
锚点是 LF 字符串，源码是 CRLF → `includes()` 永远 false。

**已修**：`.gitattributes`（`* text=auto eol=lf`）+ 28 个文件规范化。
**现在 115/115 锚点可用。**

⚠️ **新增文件时如果行尾不对，锚点会再次失效**。`verify-anchors.mjs` 是唯一能发现它的东西。

### 4.4 「验证器说通过」≠「它是真的」

- `H1–H7 只查结构，不查内容真假`。AI 自述过："七段结构全合规、健康度全过，**但有一句话在说假话**"。
- **模型的自我报告不可信**（本轮三次实证）：
  - 第 19 轮：它**虚构**了一个没犯的错（"先写引用再建文档"）；
  - 第 20 轮：它把 12 次重读说成"至少 5 次"（**低估一半**）；
  - 第 23 轮：它**归因错了**（说 `doc_handover_check` 会让指纹失效，实测那个工具一个文件都没写）。

⇒ **每条自述都要对日志。**

### 4.5 我改文案时踩的坑

改 `core/render.js` 的门禁行时，**当场废掉 1 条变异锚点**（`gate-drops-reread-notice`），
被 `verify-anchors.mjs` 立刻抓到。

⇒ **改任何文案后立刻跑 `node _m23\verify-anchors.mjs`**，不是口号。

### 4.6 pinned 预算只剩 **14 字符**

`【门禁】+【预算】+【怎么做】`三行 = 166/180（`renderM1.test.js` 有硬判据）。
**想往注入里加字只能等长替换**，不能加新行。M2.7 就是这么塞进"只读片段不算读过"的。

### 4.7 环境坑

| 坑 | 解法 |
|---|---|
| `& node ... \| Select-Object` 被拒（命名管道） | 用 `Start-Process -RedirectStandardOutput` 落盘 |
| `Start-Process` 带 `-ArgumentList` 的引号有空格/中文会解析失败 | 写成 `.ps1` 脚本文件再 `pwsh -File` |
| 会话目录：**id 在目录名里，不在文件名里**，且 `session.v4.jsonl.zstd` 可能嵌在两层子目录 | `Get-ChildItem -Recurse -Filter 'session.v4.jsonl.zstd'` |
| `data.arguments` 是 **JSON 字符串**不是对象 | `JSON.parse` 后用，直接 `.field` 永远 undefined |
| `tool/result` 的 seq 比对应 `tool/call` **大 1** | 用 `resBySeq.get(call.seq + 1)` |
