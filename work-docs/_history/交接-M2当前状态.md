# 交接 · M2 当前状态

> **这份取代 `交接-给M2施工者.md` 作为"现在到哪了"的入口。**
> 那份写的是**开工前**的状态（M1.5 修完、准备进 M2）。现在是 M2 **做了一半并封版**。

## 0. 这个项目是什么（**先读**）

**DSH 插件「文档驱动开发」（DDD，不是领域驱动设计）**：
让 AI 在改项目文档前必须先读过该读的文档，「读没读」由插件记账并在 `guard` 里用代码 `if` 强制，
不靠提示词。全局挂载（profile bundle，不做 preset），按项目激活——没有激活标记就整体 no-op。

**完整背景见 `交接-给M2施工者.md` §0**（那一节仍然有效，且被 H9 判据强制）。

## 1. 我的意图（M2 这一轮）

> **让「文档状态」从「只能问 AI」变成「一眼看得见」。**

M0 证明「AI 会先读文档」，M1 证明「交接接得住」，M1.5 证明「插件不会把项目弄坏」。
M2 要证明**最后一件**：人能不能自己看见这个约束器在干什么。

**M2 的目标不是"加个 UI"，是"换一个技术栈"**，而且只换这一次。

## 4. 坑（**这一轮新踩的，按代价排序**）

| # | 坑 | 代价 | 怎么避免 |
|---|---|---|---|
| 1 | **把 host 与 client 一次性上线** | **用户宿主起不来，被迫手工卸载** | SPEC R-11 原文就写了「先在 `cordis.patch.yml` 里不声明 `dsh.client`（**分两轮上**）」。**我读了这句但没照做** |
| 2 | **改 `apply()` 必须重启**（`inject` 只在 apply 时生效一次） | 多花了 3 次重启 | `plugin_manager` 停用/启用**不重跑 apply**。用 `_rv/probe-activate.mjs` 本地先验 |
| 3 | **`_rv/orig` 存的是修复前的代码** | 一次变异测试白跑（测了旧代码） | 改 `core/*` 后必须同步 `_rv/ddd-bundle` **和** `_rv/orig` |
| 4 | **用 shell 拼字符串改代码** | 把 151 行的 `.ts` 压成一行 | 用 `_rv/mutate-m2d.mjs` 那种可靠执行器；`Set-Content -NoNewline` 会吃掉行尾 |
| 5 | **断言没锚定作用域** | 5 次"假绿"里有 2 次是这个 | `includes('1 份')` 会命中行首的「必读 1 份」。**断言要限定到后缀段** |
| 6 | **断言比宿主严** | 逼着人去改本来对的东西 | `dsh.client.inject` 在宿主里是**可选**的；别断言"必须存在" |
| 7 | 外部 HTTP 探测无法区分"路由在"与"路由不在" | 排查绕了很久 | 宿主的认证在**路由匹配之前**，两者都 401。只能在重启后拿 200 判定 |
